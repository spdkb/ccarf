## Progress

Progress is saved in this browser only. v777 keeps its own save, separate from the v3 through v7 pages.

Use **Export backup** to download a JSON file, and **Import backup** on another browser or profile to restore it. Another browser, clearing site data, or moving the page can hide the saved progress until you import a backup.
